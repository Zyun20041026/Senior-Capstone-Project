# Credits

## Code

No third-party libraries, images, fonts, sound files or data files are
used. All graphics are drawn in code (WebGL and Canvas), and all sounds are
made in code with Web Audio (`js/audio.js`).

Most of the code was written with an AI coding tool. See
[AI_USE.md](../AI_USE.md).

## Ideas I Borrowed

- **Minesweeper.** The core rules (numbers that count hidden mines around a
  square, flags, opening an empty area) come from the classic Minesweeper
  game. Capsid Lockdown moves them onto the shell of a virus.
- **Visual style.** The way the proteins are drawn (one colour per protein
  chain, flat lit faces, shadows that fade into dots) was inspired by the
  video "Claude Mythos 5.2 predicts the structure of a therapy capsid" on
  Anthropic's Claude channel on YouTube. Screenshots of it were used as a
  style reference during design. No frames or images from the video are
  included in this project.
- **Virus shapes.** The shapes of the twelve viruses follow how they are
  usually shown in biology textbooks (for example icosahedral shells, the
  helical rod of tobacco mosaic virus, the head and tail of phage T4). All
  numbers in the game (block counts, sizes, positions of resistant
  proteins) are made up for the game.
